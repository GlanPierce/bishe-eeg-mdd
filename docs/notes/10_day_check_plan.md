- 课题方向：EEG 抑郁识别，核心路线为 EEG 预处理 + 脑网络构建 + GNN 建模 + 可视化输出。
- 已有资产：开题报告、中期报告、`notebooks/eeg666.ipynb`（含 MNE 读取 EDF、滤波、连接矩阵、PSD 分析）。
- 已部署环境：项目本地 `.venv` + PyTorch + Torch Geometric + MNE 等核心依赖。

## 检查目标定义（2026-04-27 之前）
- 代码可在本机独立运行（不依赖 Kaggle 路径）。
- 给出可复现实验最小闭环：`数据读取 -> 预处理 -> 特征/图构建 -> 模型训练/推理 -> 指标输出`。
- 留存可检查材料：运行命令、日志、结果图、核心指标表。

## 每日推进路径
1. 2026-04-18：数据路径本地化
- 把 `notebooks/eeg666.ipynb` 中 `/kaggle/input/...` 替换为本地数据目录参数。
- 约定目录：`data/raw`、`data/processed`、`outputs/figures`、`outputs/metrics`。

2. 2026-04-19：预处理脚本化
- 将 notebook 中滤波、重参考、分段逻辑提取为 `src/preprocess.py`。
- 产物：可命令行运行的预处理脚本 + 处理后样本输出。

3. 2026-04-20：特征与图构建模块
- 新建 `src/graph_builder.py`，统一输出节点特征与邻接矩阵（PCC/PLV 先做一种）。
- 固化阈值策略与频段配置（如 Alpha/Beta）。

4. 2026-04-21：模型最小版
- 先做可跑通的 baseline（MLP 或 GCN），再叠加时序模块。
- 新建 `src/train.py`、`src/eval.py`，固定随机种子与指标输出。

5. 2026-04-22：评估与对比
- 输出 Accuracy / Sensitivity / Specificity / F1。
- 对照中期报告中的连接强度、低频化倾向，整理成表格。

6. 2026-04-23：可解释性与可视化
- 输出关键脑区连接图、频谱对比图、样例预测结果图。
- 结果落地在 `outputs/figures`。

7. 2026-04-24：工程化收口
- 加 `requirements.txt`、`README`、一键运行命令。
- 至少完成一次从空环境到结果生成的完整复跑。

8. 2026-04-25：预答辩视角自查
- 对照开题承诺逐条检查：是否覆盖“多脑区、GNN、可解释、系统化流程”。
- 标注当前不足与后续补强点。

9. 2026-04-26：检查包准备
- 固定提交物：代码、依赖、运行脚本、结果图、指标表、问题清单。
- 做一次 10 分钟演示彩排（从命令执行到结果展示）。

10. 2026-04-27：代码检查日
- 现场执行最短路径命令，优先展示稳定可复现结果。
- 准备兜底方案：若训练耗时长，先演示预处理+推理与已有模型权重结果。
