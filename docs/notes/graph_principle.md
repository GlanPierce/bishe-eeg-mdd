# EEG 脑网络构图原理说明（当前实现）

本文档说明当前脚本 `src/build_graphs.py` 中“图构建”步骤的原理与实现细节，用于后续 GNN 训练阶段。

## 1. 为什么要把 EEG 构造成图

传统时序特征只强调“每个通道自身变化”，但脑电的关键在于“脑区之间的协同关系”。  
图结构可以自然表达这种关系：

- 节点（Node）：一个 EEG 通道（电极）
- 边（Edge）：两个通道之间的功能连接强度

这样后续 GNN 可以学习“通道-通道”的拓扑依赖，而不只是单通道统计量。

## 2. 当前构图流程

对每个 `TASK` 样本（一个受试者的一段 EDF）执行以下步骤：

1. 读取 EEG 并预处理  
   - 只保留 EEG 通道  
   - 带通滤波：`0.5-45 Hz`

2. 构建节点特征 `x`  
   - 用 Welch 方法估计每个通道功率谱密度（PSD）  
   - 计算五个频带相对能量：`delta/theta/alpha/beta/gamma`  
   - 每个节点特征维度为 5（即 `x.shape = [n_nodes, 5]`）

3. 构建边 `edge_index` 与 `edge_weight`  
   - 计算通道间皮尔逊相关系数矩阵（PCC）  
   - 取上三角绝对值，按分位数阈值保留强连接（默认 `q=0.8`）  
   - 若保留边过少，则至少保留 `min_edges`（默认 30）个最强连接  
   - 为兼容 PyG，边按双向存储（无向边 `i-j` 会写成 `i->j` 和 `j->i`）

4. 保存图样本  
   - 每个受试者保存为一个 `.npz`  
   - 包含：`x`, `edge_index`, `edge_weight`, `y`, `split`, `subject_id` 等字段

## 3. 数学定义（核心）

### 3.1 PCC 边权

对通道 \(i,j\) 的时间序列 \(x_i, x_j\)，边权定义为：

\[
\mathrm{PCC}(i,j)=\frac{\mathrm{cov}(x_i,x_j)}{\sigma(x_i)\sigma(x_j)}
\]

当前保留依据是 \(|\mathrm{PCC}(i,j)|\) 的强连接，符号（正负相关）保留在 `edge_weight` 中。

### 3.2 节点特征（相对频带能量）

对每个通道 \(c\)，频带 \(b\) 的特征为：

\[
f_{c,b}=\frac{P_{c,b}}{P_{c,\text{total}}}
\]

其中 \(P_{c,b}\) 为频带功率，\(P_{c,\text{total}}\) 为总功率（0.5-45Hz）。

## 4. 与中期报告“三大类”的对应关系

- 时域类：目前未直接作为节点特征输入（后续可补 RMS/样本熵/Hjorth）
- 空域连接类：本次构图的核心（PCC 邻接 + 稀疏化）
- 频域类：已作为节点特征（五个频带相对能量）

即：当前图是“频域特征 + 空域连接”融合形态，为下一步 GNN 做准备。

## 5. 当前参数（默认）

- 时间截断：`max_seconds = 120`
- 滤波：`0.5-45 Hz`
- 稀疏阈值：`pcc_quantile = 0.8`
- 最小边数：`min_edges = 30`

## 6. 输出文件说明

默认输出目录：`data/processed/graphs_pcc_task/`

- `manifest.csv`：每个图样本的索引与元数据
- `summary.json`：全局统计和配置
- `*.npz`：逐样本图数据（GNN 直接读取）

## 7. 这个图的意义（一句话）

当前图把“每个脑区有什么频域特征（节点）”和“脑区之间如何协同（边）”统一在同一结构里，目的是让后续 GNN 学习抑郁相关的脑网络模式。

## 8. 局限与下一步

当前局限：

1. 边仅基于线性相关（PCC），未覆盖非线性耦合（如 MI/PLV）。
2. 时域动态信息尚未显式建模（静态图为主）。
3. 阈值法可能对噪声敏感，后续可尝试自适应稀疏策略。

下一步建议：

1. 在同一框架加入 PLV 图，与 PCC 图做对比或融合。
2. 引入时窗切片，构建时序图（ST-GCN 或 GCN+LSTM）。
3. 在 GNN 后加入可解释性输出（关键节点/关键边贡献）。
